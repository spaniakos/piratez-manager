Optional first-party module catalogue and native WordPress install/update controls.

== Description ==
Manage PirateZ Cyberpunk, Image Optimize, Cookie Consent and Manager from the PirateZ admin menu. Every component remains independently installable and updateable. Install and activation are separate operations. Uses verified public GitHub release packages; no token required.

== Installation ==
Upload piratez-manager.zip through Plugins > Add New > Upload Plugin and activate it. Use the PirateZ admin menu. On multisite, network-activate Manager and use Network Admin > PirateZ; module activation there is network-wide.
